# 🎯 Quick Start - Deploy & Test

## 1️⃣ Deploy to Sepolia
```bash
npx hardhat run deploy/deploy.ts --network sepolia
```

**Kết quả**: 
- MockUSDC contract deployed
- SavingsPool contract deployed  
- Deployment info lưu vào `data/deployments-sepolia.json`

---

## 2️⃣ Test Contracts
```bash
npx hardhat run scripts/test.ts --network sepolia
```

**Các bước test**:
- ✅ Load deployment data từ `data/deployments-sepolia.json`
- ✅ Verify MockUSDC (name, symbol, decimals)
- ✅ Verify SavingsPool (token, owner, feeReceiver)
- ✅ Create test saving plan (90 days, 5% APR)
- ✅ Fund vault với 100 USDC
- ✅ Generate test report → `data/test-report-sepolia.json`

## 💡 Common Commands

```bash
# Compile
yarn compile

# Test locally
yarn test

# Deploy to Sepolia
npx hardhat run deploy/deploy.ts --network sepolia

# Test on Sepolia
npx hardhat run scripts/test.ts --network sepolia

# Hardhat console on Sepolia
npx hardhat console --network sepolia

# View accounts
npx hardhat accounts

# Gas report
REPORT_GAS=true yarn test
```

## ⚠️ Before Deploy

✅ Check `.env` has valid `TESTNET_PRIVATE_KEY`  
✅ Ensure account has ETH on Sepolia (get from [faucet](https://sepoliafaucet.com))  
✅ Run `yarn compile` successfully  
✅ Review deploy parameters in `deploy/deploy.ts`
