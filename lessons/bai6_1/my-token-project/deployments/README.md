# Deployments

Thư mục này chứa thông tin các contract đã deploy lên các mạng khác nhau.

- `sepolia/` - Deployment trên Sepolia testnet
- `localhost/` - Deployment trên local Hardhat network

Mỗi khi deploy, hardhat-deploy sẽ tự động tạo file JSON chứa:
- Địa chỉ contract
- ABI
- Bytecode
- Transaction hash
- Thông tin deployer
